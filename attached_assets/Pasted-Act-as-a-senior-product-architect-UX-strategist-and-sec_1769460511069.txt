================================================
GLOBAL RULES
================================================
- Dark Theme with Blue primary color

================================================
ROLES
================================================
1) Admin (Founder)
2) Support (Customer Support)

================================================
ORDERS MANAGEMENT – UPDATED RULES
================================================

1) ORDER DELETION
- Admin AND Support must be able to DELETE orders.
- Designers must NOT be able to delete orders.
- Deleted orders move to status: **Canceled** (soft delete).
- Canceled orders must remain visible in reports (Admin only).

2) MULTIPLE SERVICES DISPLAY (UI BEHAVIOR)
- One Order can contain multiple services.
- In Orders table:
  - Show only a short summary (e.g. “3 Services”).
  - On hover OR click tooltip:
    - Display full list of services (CVs, Cover Letters, LinkedIn, etc.).
- Client, Designer, and Admin should NOT see all services expanded by default.

3) PAYMENT STATUS (EDITABLE)
- Payment Status must be editable by:
  - Admin
  - Support
  - Designer
- Allowed values:
  - Pending
  - Paid
- No payment amounts visible to Support or Designers.

4) DESIGNER DATA VISIBILITY
- Designers can see ONLY orders assigned to them.
- Designers cannot see:
  - Other designers’ orders
  - Finance totals
  - Admin reports

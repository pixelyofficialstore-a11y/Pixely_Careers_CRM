================================================
NAVIGATION & NAMING
================================================
* Rename the existing “Chats” section to **WhatsApp**
* Clicking “WhatsApp” opens a dedicated WhatsApp module (same app, new tab/route)

================================================
ACCESS & VISIBILITY RULES
================================================

ADMIN:
* Can see ALL WhatsApp chats
* Can read all messages
* Can send messages, files, voice notes
* Can assign / reassign chats
* Can change chat tags
* Can view linked Order details

SUPPORT:
* Can see ALL WhatsApp chats
* Same permissions as Admin except:
  - Cannot delete chats
  - Cannot access finance

DESIGNER:
* Can see ONLY chats assigned to them
* Can reply, send files, send voice notes
* Can change chat tags for their assigned chats
* Cannot see unassigned chats

================================================
WHATSAPP UI STRUCTURE
================================================

LEFT SIDEBAR (Admin & Support):
* Tabs:
  - All Chats
  - New Chats
  - By Designer (list of designers → assigned chats)

LEFT SIDEBAR (Designer):
* Tabs:
  - My Chats
  - New Chats

CHAT LIST:
* Client name / number
* Last message preview
* Assigned designer (Admin/Support only)
* Chat tag (color-coded)
* Unread indicator

================================================
CHAT TAG SYSTEM (MANDATORY)
================================================

Available tags:
* New
* Working
* Pending
* Changes
* Issues
* Satisfied Client

Rules:
* Admin & Support can change tags for any chat
* Designer can change tags ONLY for assigned chats
* When Designer sets tag = **Satisfied Client**:
  - Chat is automatically UNASSIGNED from that designer
  - Chat moves out of Designer’s view
  - Chat remains visible to Admin & Support

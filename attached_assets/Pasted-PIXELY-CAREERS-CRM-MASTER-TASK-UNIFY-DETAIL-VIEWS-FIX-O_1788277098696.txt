==================================================
PART 7 — CANCELLATION MUST BE ATOMIC
==================================================

Where possible perform cancellation operations server-side atomically.

For Refunded cancellation:

1. Store cancellation reason.
2. Mark Order canceled.
3. Store advance_refunded = true.
4. Record refund amount.
5. Update/derive finance exclusion.
6. Write Activity.
7. Write audit history.

For Non-refunded cancellation:

1. Store cancellation reason.
2. Mark Order canceled.
3. Store advance_refunded = false.
4. Keep advance collected.
5. Remove remaining receivable.
6. Write Activity.

Do not allow half-updated Orders.

==================================================
PART 8 — DUPLICATE CANCELLATION PROTECTION
==================================================

Once Order is canceled:

Do not allow Cancel Order again.

Do not allow duplicate refund.

Do not subtract the same financial amount twice.

Make operation idempotent.

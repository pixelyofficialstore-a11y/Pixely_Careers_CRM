PIXELY CAREERS CRM
TASK: IMPLEMENT CONTEXT-AWARE NESTED DRAWER NAVIGATION

==================================================
MAIN PROBLEM
==================================================

The CRM currently has cross-module navigation between:

Orders
Complaints
Reviews
Suggestions

but the current behavior is not ideal.

Example current behavior:

1. User is on Orders Page.
2. Opens Order PX-2609-002 in right-side Order Details drawer.
3. Goes to Client Experience.
4. Clicks Complaint CMP-2609-004.
5. CRM navigates to the Complaints Page.
6. Complaint drawer opens there.
7. To return to the Order, user must close Complaint, return to Orders, find the Order again and reopen its details.

THIS IS BAD UX.

It destroys context and makes navigation unnecessarily complicated.

==================================================

==================================================

The BACKGROUND PAGE MUST NEVER CHANGE when opening a related record from an Order.

Example:

User starts here:

ORDERS PAGE
↓
Order PX-2609-002 drawer opened
↓
Client Experience tab
↓
Clicks CMP-2609-004

NEW BEHAVIOR:

Orders Page REMAINS in the background.

The current right-side drawer changes from:

ORDER DETAILS

to:

COMPLAINT DETAILS

The Complaint drawer should show a BACK button at the top.

Clicking BACK:

returns to the previous:

ORDER DETAILS

drawer.

It must return to:

PX-2609-002
Client Experience tab
same scroll/context if practical.

The user must NOT be navigated to the Complaints Page.

GENERAL NAVIGATION PRINCIPLE
==================================================

Feedback = Client feedback workspace.

If related records are opened from within another record:

Use nested drawer navigation.

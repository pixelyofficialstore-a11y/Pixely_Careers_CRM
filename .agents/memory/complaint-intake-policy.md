# Complaint intake policy

Admin-filed complaints are authoritative and enter the workflow as valid. Complaints filed by support/sales enter the review queue and can become valid only through an explicit admin decision.

**Why:** The owner distinguishes an admin finding from a sales/support report that still requires verification.

**How to apply:** Preserve this distinction in every complaint entry point, import, and API. Admin-managed category changes affect future dropdown options only; existing complaints retain their original category key and label fallback for audit history.
